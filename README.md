# LocalBox


[<img src="https://play.google.com/intl/en_us/badges/images/badge_new.png">](https://play.google.com/store/apps/details?id=com.petertieu.android.localbox)


## Description
Break language barriers and communicate with speakers of the 12 supported languages using some of the most commonly spoken everyday words and phrases.

Great for English speaking tourists or learners of the these languages.

## Languages Supported
Arabic, Chinese, French, German, Hindi, Italian, Japanese, Korean, Russian, Spanish. Thai, Vietnamese.


## Features
Words and phrases that come equipped with sounded pronunciation, translated text, as well as caption of how to pronounce them!


## Also Includes
Modifiable playback speed to suit the pace you want to hear the pronunciation!
